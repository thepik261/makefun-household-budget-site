Home Ledger — a household budget site for the Alvarez household: a dashboard with monthly income, spending, savings rate and a spending-by-category donut, transactions you can add, filter and delete, editable category budgets with progress bars, savings goals, monthly reports with income-vs-spending charts and plain-language insights, and a bills list with mark-paid controls. Everything runs in the browser and is saved on the device, with realistic seeded data for September–November 2026 and a layout that works on a phone.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
